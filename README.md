# AL AMIR DELIVERY

A Flutter interface demo for AL AMIR DELIVERY with Arabic, Sorani Kurdish, and English language options.

## Guest access

From the welcome screen, select **Continue**, then choose **Continue as guest** on the login screen. Guest users can access the limited dashboard and fill out a demo order form without account credentials.

> This repository contains a UI demo only. Guest orders are validated and acknowledged locally; they are not saved to a server or sent to a restaurant. Authentication and order submission require a backend integration.

## Run

With Flutter installed:

```sh
flutter pub get
flutter run
```
